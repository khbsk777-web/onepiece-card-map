# ⚓ トレジャーカードマップ（非公式）

ワンピースカードの入荷・在庫情報を、みんなで地図に報告し合う非公式Webアプリです。
※ バンダイ・集英社・東映アニメーション等とは関係ありません。公式ロゴ・画像・公式データは使っていません。

## できること
- 地図でお店ごとの在庫状況を色で確認（🟢あり／🟡わずか／🔴売切／🔵入荷予定／⚪情報なし・古い）
- 絞り込み：在庫あり／今日の情報／商品／都道府県
- お店の登録（店名検索 or 地図タップ）
- 在庫の報告（商品・弾番号・状態・売り方・メモ）
- 👍役に立った・🚩通報（1人1回）、ポイント（報告10pt・👍5pt）
- 🆕 新着の報告一覧、現在地ボタン

## セキュリティのしくみ
| 守りたいこと | どうやって守るか |
|---|---|
| なりすまし・捨てアカ | メール確認済み or Googleログインの人だけ投稿できる |
| 他人の投稿の改ざん | `firestore.rules` で「自分の報告だけ削除可・書き換えは不可」 |
| 👍・通報の水増し | 1人1回の印をサーバー側で確認。自分の投稿には押せない |
| 商品名 | 報告に商品名（例：最強の戦士）を入れられる。みんなの入力から候補を出す（30文字まで・URL不可） |
| 連投・荒らし | 報告もお店の登録も5秒に1回まで（サーバー側で判定）。投稿は現在地から3km以内のお店だけ |
| 変なデータ | 文字数・選択肢・日本の範囲内の座標・都道府県をサーバー側でチェック |
| スパム・いたずらコード | URLや `<` `>` は禁止。表示は必ず文字として扱う（XSS対策）。CSPで外部スクリプトを制限 |
| ボット | App Check（reCAPTCHA v3）に対応 |
| 個人情報 | 公開はニックネームだけ。メールは非公開。現在地は保存しない |
| 不適切な投稿 | 通報3件で自動非表示。お店の修正・削除は管理者のみ |
| 写真 | 端末で小さく圧縮し、位置情報などの隠れた情報を消してから保存。JPEGだけ受け付け、1分に1回まで |

## 公開までの手順（はじめての人向け）
1. **GitHub** で新しいリポジトリ `onepiece-card-map` を作り、このフォルダの中身を全部入れる
2. **Firebase**（https://console.firebase.google.com）でプロジェクトを作る（無料のSparkプランでOK）
3. 「Authentication」→「ログイン方法」で **メール/パスワード** と **Google** をオン
4. 「Firestore Database」を作成（場所は `asia-northeast1` 東京）
5. 「Firestore」→「ルール」に `firestore.rules` の中身を貼って **公開**
6. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリを追加 → 表示された設定を `firebase-config.js` に貼る
7. GitHub の Settings → Pages で公開（Branch: main / root）
8. Firebase「Authentication」→「設定」→「承認済みドメイン」に `あなたの名前.github.io` を追加
9. （おすすめ）App Check を reCAPTCHA v3 で登録 → サイトキーを `firebase-config.js` の `appCheckSiteKey` に入れる → 動作確認後に「適用」をオン
10. （おすすめ）Google Cloud コンソール →「認証情報」→ APIキーに **HTTPリファラー制限**（`https://あなたの名前.github.io/*`）をつける

`firebase-config.js` が空のままだと **デモモード**（データはその端末の中だけ）で動きます。

## 管理者のお仕事
- 通報が多い報告・まちがったお店は Firebase コンソールの Firestore から削除
- 利用者が増えたら（目安：お店5,000件以上）、読み込みを地域ごとに分ける改修が必要

## ファイル
- `index.html` / `style.css` … 画面
- `app.js` … 画面の動き
- `backend-firebase.js` … 本番（Firebase）とのやりとり
- `backend-demo.js` … デモモード
- `firestore.rules` … セキュリティルール（いちばん大事）
- `tests/rules.test.mjs` … ルールの自動テスト（Firebaseエミュレーターで実行）
- `vendor/leaflet/` … 地図ライブラリ（外部CDNを使わず同梱）
