このアプリについて

トレジャーカードマップは、ワンピースカードゲームの入荷・在庫情報を、みんなで報告し合って地図で見られる無料の非公式ファンツールです。

非公式です。株式会社バンダイ、株式会社集英社、東映アニメーション株式会社、その他の権利者・メーカー・お店とは一切関係ありません。

「ONE PIECE」「ワンピースカードゲーム」などの名前は、それぞれの権利者の商標または登録商標です。このアプリでは、商品を説明するためだけに使っています。キャラクターの画像やロゴは使っていません。

  • 見るだけなら、ログインなしで使えます。
  • 在庫の報告・👍・通報・写真の投稿には、ログインが必要です。
  • 広告はありません。利用料もかかりません。
  • 在庫の情報は利用者からの報告です。正しいとは限らないので、参考として使ってください。
  • お店への在庫の問い合わせや、店員さんへの迷惑になる行動はやめましょう。

安心して使うための対策

  • 通信はすべて暗号化（HTTPS）しています。
  • メールアドレスは公開されません。ほかの人に見えるのは、ニックネームと、あなたが投稿した報告・写真だけです。
  • パスワードは、このアプリの運営者にも見えません。ログインはGoogleのしくみ（Firebase Authentication）で行っています。
  • なりすまし対策：メールの確認が終わった人だけが投稿できます。他人の名前で投稿したり、他人の報告を書き換えたり消したりはできません。
  • 荒らし対策：連続投稿は5秒に1回、写真は1分に1回までです。URLの入った投稿はできません。通報が3件集まった報告・写真は自動で非表示になります。
  • ウソの報告の対策：報告・写真の投稿・お店の登録は、現在地から3km以内のお店だけできます。
  • 写真の位置情報は消します。写真は投稿前に端末の中で縮小・変換するので、撮影場所などの情報（Exif）は送られません。
  • データベースのルールは、変更のたびに自動テストを行い、合格したものだけを使っています。
  • アプリの中で動くプログラムは、決められた場所のものだけに制限しています（CSP）。

プライバシーポリシー

制定日：2026年11月28日

1. 集める情報と使い方

情報使い道ほかの人に見える？
メールアドレスログイン、確認メール・パスワード再設定メールの送信見えない
ニックネーム報告・写真といっしょに表示見える
在庫の報告・写真・登録したお店地図に表示して、みんなで共有見える
👍・通報の記録1人1回にするため、荒らし対策のため人数だけ見える
最後に投稿した時刻連続投稿の制限見えない
現在地地図の表示と「3km以内か」の判定。この判定は端末の中だけで行い、運営者のサーバーには送らず、保存もしません。見えない

本名・住所・電話番号などは集めません。ニックネームに本名は使わないでください。

2. 使っている外部のサービス

  • Google Firebase（ログイン・データの保存）
  • GitHub Pages（アプリの配信。通常のアクセス記録が残ることがあります）
  • OpenStreetMap / Overpass API / Nominatim（お店の情報と住所の検索。表示中の地図の範囲や、検索欄に入れた言葉が送られます）
  • 国土地理院（地図・航空写真の画像）
  • Googleログイン（Googleでログインする場合のみ）

それぞれのサービスの情報の扱いは、各社のプライバシーポリシーに従います。広告やアクセス解析のツールは使っていません。

3. 端末に保存する情報

ログインの状態、最近入力した商品名、表示の設定を、あなたの端末（ブラウザ）に保存します。ブラウザのデータを消すと消えます。

4. ほかの人に渡すこと

法律で必要な場合を除き、あなたの情報を本人の同意なくほかの人に渡したり、売ったりすることはありません。

5. 削除

  • 自分の報告・写真は、いつでもアプリから削除できます。
  • ログイン後、右上のニックネーム →「アカウントを削除」で、メールアドレス・ニックネーム・自分の報告・自分の写真をまとめて削除できます。
  • 👍・通報の「押した印」と、連続投稿の制限のための時刻の記録は、不正防止のため残ります（だれのものかは、ほかの人には分かりません）。

6. 変更

このポリシーを変えるときは、このページでお知らせします。

よくある質問

お金はかかりますか？

かかりません。広告もありません。

公式のアプリですか？

いいえ。ファンが作った非公式のアプリで、メーカーやお店とは関係ありません。

報告できません

次の3つを確認してください。①メールの確認リンクを押した　②位置情報を「許可」にした　③現在地から3km以内のお店を選んでいる（地図の緑の円の中）

現在地が出ません

iPhoneは「設定」→「プライバシーとセキュリティ」→「位置情報サービス」→「Safari」を「使用中のみ」にしてください。

間違った報告を見つけたら？

報告の「通報」ボタンを押してください。3件集まると自動で非表示になります。

自分の報告を消したい

自分の報告にある「削除」ボタンから消せます。アカウントごと消すこともできます。

ホーム画面に置けますか？

Safariの共有ボタン →「ホーム画面に追加」で、アプリのように使えます。
